# 單元回寫知識地圖流程

建立：2026-09-13（依四上 U1/U2 回寫實作整理）
適用：某單元完成備課分析或互動教具後，把成果補進 `data/units.json`。

範例成品：
- 審核表：`四上U1U2教具回寫審核表.md`
- 寫入腳本範本：`scripts/writeback_template_g4a_u1u2.py`
- 紀錄：`CHANGELOG.md` @2026-09-13

---

## 八步流程

```
① 對照三下範本，找出缺什麼
② 抽來源：教冊、課綱、課本逐頁全文
③ 產審核表          ★ 停在這裡，等使用者裁決
④ 使用者勾選／說「寫入」
⑤ 腳本寫入（備份＋無損＋只動目標單元）
⑥ 驗證：檢查腳本＋網站三個分頁
⑦ 更新文件
⑧ commit 指定檔案；push 前確認只領先 1 個 commit
```

### ① 對照三下範本

三下 9 個單元是欄位完整度的參考範本。逐欄比數量：

```python
import json
d = json.load(open('data/units.json', encoding='utf-8'))
for x in d:
    if (x['grade'], x['semester']) == (3, 2) or x['id'].startswith('4u-u1-'):
        print(x['id'], {k: len(v) for k, v in x.items() if isinstance(v, list)},
              [i['code'] for i in x['indicators']])
```

四上 U1/U2 比對時發現的典型缺口：
- `indicators` 只有學習內容（N-），**缺學習表現**（n-II-）
- `concept_relations` 沒有 **「易錯影響」**（迷思 → 受影響概念）
- `objectives` 比教冊「本單元」條數少

### ② 抽來源

| 要補的 | 去哪裡找 | 注意 |
|---|---|---|
| 學習表現 | 教冊（資料篇）單元開頭「連結架構」頁的「學習表現」格 | 同頁有其他領域指標（如社會領域 `3d-II-1`），不要誤收 |
| 學習表現原文 | 課綱 PDF（`數學學習地圖/十二年國民基本教育課程綱要…數學領域.pdf`）p12 | 教冊與課綱文字要一致才寫 |
| 單元目標 | 教冊「連結架構」頁下方「本單元」條列 | 照抄原文 |
| 活動頁碼與內容 | `教材/四上/課本/NN_單元名.pdf`，用 pdfplumber 逐頁抽全文 | **以頁尾印刷頁碼為準**，見坑 1 |
| 迷思的課本對應 | 同上，找到課本真正出現該題型的頁與圈號題號 | 見坑 2 |
| 備課提醒 | 課本原文、課本教師註記、教冊教學注意事項 | 「課本說」「教冊說」分開寫 |

抽課本全文：

```python
import pdfplumber
p = pdfplumber.open('教材/四上/課本/01_一億以內的數.pdf')
for i, pg in enumerate(p.pages):
    print(f'#### PDF頁{i+1}\n', pg.extract_text())
```

四上課本 PDF 會把字元重複輸出（`1100 張` ＝ 10 張、`紮紮成` ＝ 紮成），**讀懂即可，不要自動去重**（會誤傷「十萬」這類單字）。

### ③ 審核表

放在 knowledge-map 根目錄，檔名 `<學期><單元>…回寫審核表.md`。每一項都用 `- [ ]`，並附來源。必含四段：

1. **對照範本的缺口表**（欄位 × 範本 × 本單元 × 判斷）
2. **可補項目**：學習表現、單元目標、易錯影響、活動內容、備課提醒、迷思課本對應
3. **待核對、這次不寫**：證據不足的項目
4. **刻意不寫回**：沒有教材證據的錯誤類型、太細的微技能、設計者自己的判斷、方法心得

### ④ 使用者裁決

未獲使用者「寫入」前**不動 units.json**。要問的決策：
- 活動格式：只加頁碼，或「名稱＋頁碼＋一句內容」（四上 U1/U2 採後者）
- 全部寫入或逐項勾選

### ⑤ 腳本寫入

複製 `scripts/writeback_template_g4a_u1u2.py` 改內容。範本已內建四道保護，**不要拿掉**：

1. **無損重寫檢查**：`json.dumps(d, ensure_ascii=False, indent=2) == 原檔`，不等就停（格式：縮排 2、中文不轉碼、檔尾無換行）
2. **只動目標單元**：寫入前後比對其他所有單元，有變就停
3. **可重跑（冪等）**：加指標、關係、課本對應前先檢查是否已存在
4. **關係名稱查證**：`to` 必須是本單元已有的 concept name

寫入前先備份：`cp data/units.json data/units.json.bak_YYYYMMDD`

### ⑥ 驗證

```bash
node scripts/check-all-completion-gaps.js   # 含資料品質、卡片渲染、各學期完整度
```

網站卡片分三個分頁，**三個都要檢查**（預設只顯示「概念」）：

| 分頁 | 顯示 |
|---|---|
| 概念 `concepts` | 核心概念、迷思（容易卡住的點）、先備後續 |
| 關聯 `relations` | concept_relations（含易錯影響） |
| 來源 `sources` | 課綱指標、學習目標、課本活動、教學工具、備課提醒 |

本機：在 `康軒數學/` 跑 `python -m http.server 8765`，Playwright 開 `knowledge-map/index.html`，
`selectUnit('<unit id>')` → `setCardTab('concepts'|'relations'|'sources')`，檢查文字與 pageerror，驗完關掉伺服器。

### ⑦ 更新文件

- `knowledge-map/CHANGELOG.md`：頂端新增
- `knowledge-map/CLAUDE.md` frontmatter：`version`／`next_action`／`updated`（無 BOM）

- `units.json.bak_*` 不進版控

## 各欄位寫法規格

| 欄位 | 寫法 | 範例 |
|---|---|---|
| `indicators` | 追加 `{code, text}`，text 照課綱原文 | `{"code":"n-II-2","text":"熟練較大位數之加、減、乘計算或估算，並能應用於日常解題。"}` |
| `objectives` | 教冊「本單元」原文，整段替換 | `能熟練乘法直式計算。` |
| `activities` | `名稱（p起–迄）：一句內容`。**只放課本編號活動** | `十萬以內的數（p6–9）：10 張 1000 元紮成一疊＝1 萬…` |
| `notes` | 接在原文後面；非編號活動（開門活動、練習百分百、素養吧）寫這裡 | `另有兩段非編號活動：開門活動（p19）…` |
| `misconceptions[].description` | 末尾加 `。課本對應：…`，用頁碼＋圈號題號 | `課本對應：活動二第⑥題（p25，28×74）` |
| `concept_relations` | `{from: 迷思 name, to: 概念 name, type: "易錯影響", note}` | `大數減法借位錯誤 → 大數的加減` |

**不因補了課本對應就升級 `evidence_level`。** 課本出現某題型 ≠ 教材明文指出學生常錯。

## 踩過的坑

1. **設計文件的頁碼可能是 PDF 頁碼**。U1 設計文件寫「p2–5」，實際課本印刷頁是 p6–9（U1 印刷頁＝PDF 頁＋4）；U2 設計文件卻是印刷頁。**一律回課本 PDF 看頁尾**。
2. **設計文件的圈號可能是設計者自編的步驟號**，不是課本題號（U1「活動一①～⑫」）。
3. **網站會替活動自動編號 1、2、3**。把開門活動放進 `activities` 會讓「四位數×一位數」變成第 2 個，跟課本的活動一錯開 → 非編號活動寫進 `notes`。
4. **教冊連結架構頁混有其他領域指標**：U2 同頁的 `3d-II-1` 是社會領域。
5. **⚠️ `scripts/sync-g4a-concepts.js` 會整批覆蓋四上的 `concepts`、`misconceptions`、`concept_relations`**（改由 `數學學習地圖/data/concepts.csv`、`relations.csv` 產生）。四上迷思與易錯影響關係都不在那兩個 CSV 裡，**重跑會清掉**。要重跑前先把這些資料補進 CSV，或改腳本保留既有欄位。
6. 同一件事「課本說」和「教冊說」可能不同（進位記號：課本 p21 上方、課本 p25 註記記在心裡、教冊下方）→ 三種都列，不宣稱只有一種對。
